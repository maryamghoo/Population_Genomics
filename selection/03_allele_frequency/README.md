# Nonsynonymous SNP Allele-Frequency Analysis

## Overview
This workflow identifies nonsynonymous SNPs among FDR-significant outlier loci annotated with ANNOVAR, extracts those SNPs from the filtered VCF, calculates allele frequencies across genetic clusters, and summarizes and visualizes their distribution using R.

The workflow consists of two scripts that should be run in order:

See:  
1. `nonsynonymous_snp_frequencies.sh`  
2. `nonsynonymous_snp_frequencies.R`

## Purpose
This workflow is used to further characterize nonsynonymous SNPs identified among candidate loci under selection and evaluate differences in their alternate allele frequencies among genetic clusters.

The workflow performs:

- Identify nonsynonymous SNPs from ANNOVAR annotation results
- Extract nonsynonymous SNPs from the SNP VCF
- Generate a compressed and indexed VCF containing only nonsynonymous SNPs
- Calculate allele frequencies separately for each genetic cluster
- Combine cluster-specific allele-frequency results
- Summarize candidate genes containing nonsynonymous and start-loss variants
- Combine SNP annotations with allele-frequency information
- Map gene IDs to gene symbols
- Determine the distribution of genes among genetic clusters
- Filter genes based on alternate allele frequency for visualization
- Generate alternate allele-frequency plots
- Export summary tables and figures

## 1. Bash Nonsynonymous SNP and Allele-Frequency Workflow

### Purpose
The Bash workflow identifies nonsynonymous SNPs from the ANNOVAR annotation results, extracts those SNPs from the original SNP VCF, and calculates allele frequencies separately for each genetic cluster.

### Expected Inputs
- ANNOVAR multi-annotation output:
`bash_data/fdr_outliers_annotated.fsj_multianno.txt` generated by the ANNOVAR annotation workflow.
- Filtered SNP VCF that should contain the SNPs from which the BayeScan outlier loci were identified.
`snps_afterLD_unrelated.vcf.gz`
- Genetic-cluster sample lists:
```
/bash_data/sample_lists/archbold.txt
/bash_data/sample_lists/cbc.txt
/bash_data/sample_lists/sbc.txt
/bash_data/sample_lists/sl.txt
/bash_data/sample_lists/ocala.txt
/bash_data/sample_lists/merritt.txt
```
Each sample-list file contains the sample IDs belonging to one genetic cluster. For example:
```
sample01
sample02
sample03
sample04
```
The sample IDs must match the sample names in the VCF.

### Output
The expected generated files can be found in `bash_results/`
- Nonsynonymous SNP coordinates:
`nonsynonymous_snps.txt`
- Nonsynonymous SNP VCF:
`nonsynonymous_snps.vcf.gz`
- VCF index:
`nonsynonymous_snps.vcf.gz.csi`
- Genetic-cluster-specific frequency files:
`frequencies/<cluster>_freq.frq`
- Combined allele-frequency table:
`all_pop_freq.txt`


### Identify Nonsynonymous SNPs

The script searches the ANNOVAR `ExonicFunc.refGene` column and retains variants annotated as `nonsynonymous SNV`.

For each nonsynonymous SNP, chromosome, start, and end coordinates are extracted. 

The resulting file is `bash_results/nonsynonymous_snps.txt`, which is used as a region list for `bcftools`.


### Extract Nonsynonymous SNPs from the VCF

`bcftools view` uses `nonsynonymous_snps.txt` to extract the corresponding variants from the input VCF.

The resulting compressed VCF is `nonsynonymous_snps.vcf.gz`.

The VCF is then indexed, producing `bash_results/nonsynonymous_snps.vcf.gz.csi`.


### Calculate Genetic-Cluster Allele Frequencies

`VCFtools` calculates allele frequencies independently for each genetic cluster using the corresponding sample-list file.

The resulting frequency files in this study are:
```
archbold_freq.frq
cbc_freq.frq
sbc_freq.frq
sl_freq.frq
ocala_freq.frq
merritt_freq.frq
```

The script then combines these files into a single table: `all_pop_freq.txt`

### Usage
- This script was run using `bcftools v1.20` and `vcftools v0.1.17`. Ensure they are installed and available in the environment.
- Adjust SLURM job settings (partition, CPUs, memory, runtime, log paths, etc.) based on the cluster configuration and dataset size.
- Update the following in `nonsynonymous_snp_frequencies.sh` as needed:
```
/nonsyn_freq/logs/nonsyn_freq.out
/nonsyn_freq/logs/nonsyn_freq.err

DATA_DIR="bash_data"
OUTDIR="bash_results"

VCF="/path/to/snps_afterLD_unrelated.vcf.gz"
SAMPLE_DIR="${DATA_DIR}/sample_lists"
```
- Update the genetic-cluster names to correspond to the sample-list filenames:
```
POPULATIONS=(
  "archbold"
  "cbc"
  "sbc"
  "sl"
  "ocala"
  "merritt"
)
```
- Submit the job:
`sbatch nonsynonymous_snp_frequencies.sh`


## 2. R Nonsynonymous SNP Analysis and Visualization

### Purpose
The R workflow summarizes nonsynonymous SNP annotations, combines them with genetic-cluster allele frequencies, and visualizes alternate allele frequencies among genetic clusters.

The script performs:

- Identify nonsynonymous SNPs from ANNOVAR results
- Generate a candidate-gene summary table
- Combine SNP annotations with allele-frequency results
- Map gene IDs to gene symbols
- Generate gene and SNP allele-frequency tables
- Summarize gene presence among genetic clusters
- Filter genes for visualization based on alternate allele frequency
- Generate alternate allele-frequency plots
- Export figures in PDF, PNG, and SVG formats

### R Packages
The script requires:

- `dplyr`
- `readr`
- `stringr`
- `ggplot2`

### Expected Input
The following files are used:
- ANNOVAR annotation file from `bash_data/`:
`fdr_outliers_annotated.fsj_multianno.txt`
- Combined genetic-cluster allele-frequency table from `bash_results/`:
`all_pop_freq.txt`

### Output
`candidate_genes_table.csv`  
`gene_snp_frequencies.csv`  
`gene_cluster_distribution.csv`  
`gene_frequency_plot.png`  
`gene_frequency_plot.pdf`  
`gene_frequency_plot.svg`
saved in: `r_results/`. SVG format is useful for opening figures in vector graphic editors such as Inkscape, allowing manual adjustment and editing of individual image elements without loss of quality.

### Usage
- Run `nonsynonymous_snp_frequencies.sh` before running the R workflow.
- Adjust the gene ID-to-symbol mapping, genetic-cluster names, plotting order, color palette, and allele-frequency threshold as needed for your dataset.
- Update the following in `nonsynonymous_snp_frequencies.R` if needed:
```
bash_data <- "bash_data"
bash_dir <- "bash_results"
output_dir <- "r_results"
```
- The current visualization retains genes with an alternate allele frequency of at least `0.20` in one or more genetic clusters. Adjust this threshold as needed.


## Important Notes

- The Bash and R scripts should be run in order.
- The ANNOVAR annotation file must contain the expected `ExonicFunc.refGene` and `AAChange.refGene` fields.
- Sample IDs in the genetic-cluster sample lists must exactly match sample IDs in the input VCF.
- The input VCF should correspond to the SNP dataset used to identify the candidate outlier loci.
- The gene ID-to-symbol mapping in the R script is specific to the annotation used in this study and should be updated for other datasets.
- The genetic-cluster names and their display labels are manually defined and should be adjusted for other datasets.
- The alternate allele-frequency threshold of `0.20` is used only to select genes for the final visualization.
- Update all `/path/to/...` locations before running the workflow.
- Check the SLURM output and error logs after the Bash job completes.
