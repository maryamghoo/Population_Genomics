# GO Enrichment Analysis Pipeline

## Overview
This workflow performs Gene Ontology (GO) enrichment analysis of genes associated with FDR-significant outlier SNPs identified by BayeScan and annotated using ANNOVAR.

The pipeline includes:

- Extraction of candidate genes from ANNOVAR results
- Extraction of background genes from the genome annotation
- Generation of gene-to-GO mappings
- Verification of candidate genes against the background gene set
- GO Biological Process enrichment analysis using `topGO`
- Fisher's exact test with the `weight01` algorithm
- Benjamini-Hochberg FDR correction
- Identification of raw and FDR-significant GO terms
- GO enrichment visualization

See:  
`prepare_GO.sh`  
`GO_enrichment.R`

## 1. Bash GO Preparation Workflow

### Purpose
The Bash workflow prepares the candidate gene list, background gene list, and gene-to-GO mapping required for GO enrichment analysis.

The script performs:

- Extract candidate genes from ANNOVAR results
- Split SNP annotations associated with multiple genes into individual gene IDs
- Remove missing gene annotations
- Extract all genes from the GFF3 annotation as the background gene set
- Extract gene-to-GO associations from the GFF3 annotation
- Identify candidate genes missing from the background gene set
- Report basic gene and GO mapping counts

### Expected Input
- ANNOVAR annotation of FDR-significant outlier SNPs:
`bash_data/fdr_outliers_annotated.fsj_multianno.txt`
- Genome annotation containing gene IDs and GO annotations:
`/path/to/genome_annotation.gff3`

### Output
`candidate_genes.txt` contains the unique genes associated with FDR-significant outlier SNPs.
`all_genes.txt` contains the background gene set extracted from GFF3 rows with feature type `gene`. 
`candidate_genes_missing_from_background.txt` contains candidate genes that could not be found in the background gene set. Ideally, this file should be empty.
`gene2go_map.txt` contains unique gene-to-GO associations in the format: 
```
g42    GO:0006357
g42    GO:0007155
g535   GO:0006915
```
saved in: `bash_results/`.


The script uses the `Gene.refGene` column to identify genes associated with the candidate SNPs.

Entries containing multiple genes, for example:
```
g42;g43
g534;NONE
NONE;g535
```
are split into individual gene IDs. Missing annotations (`NONE`, `.`, and empty values) are removed.

The GFF3 file is used to generate both the background gene set and gene-to-GO mapping.

The current script expects gene IDs in the form:
```
g42
g535
g11583
```
and GO terms in the form:
```
GO:0006357
GO:0007155
```


### Usage
- Adjust SLURM job settings (partition, CPUs, memory, runtime, output paths, etc.) based on your cluster configuration and dataset size.
- Update the following in `prepare_GO.sh` as needed:
```
/prepare_GO/logs/prepare_GO.out
/prepare_GO/logs/prepare_GO.err

DATA_DIR="bash_data"
OUTDIR="bash_results"

GFF3="/path/to/genome_annotation.gff3"
```
- The current gene-ID extraction assumes IDs follow the `g<number>` format. Modify the extraction pattern if a different gene-ID format is used.
- Submit the job:
`sbatch prepare_GO.sh`


## 2. R GO Enrichment Analysis and Visualization

### Purpose
The R workflow performs GO Biological Process enrichment analysis using the candidate genes, background genes, and gene-to-GO mapping generated by the Bash workflow.

The script performs:

- Import candidate and background gene lists
- Import gene-to-GO mappings
- Create the candidate/background gene vector
- Construct a `topGOdata` object
- Perform Biological Process enrichment analysis
- Run Fisher's exact test using the `weight01` algorithm
- Calculate Benjamini-Hochberg FDR across all tested GO terms
- Identify GO terms with raw p-value < 0.05
- Identify GO terms with FDR < 0.05
- Export complete and significant GO enrichment results
- Generate GO enrichment plots
- Distinguish raw-significant and FDR-significant terms in the visualization
- Export figures in PDF, PNG, and SVG formats

### R Packages
The script requires:

- `topGO`
- `GO.db`
- `ggplot2`

### Expected Input
can be found in `bash_results/` folder:
- Candidate gene list:  
`candidate_genes.txt`
- Background gene list:  
`all_genes.txt`
- Gene-to-GO mapping:  
`gene2go_map.txt`

### Output
`GO_enrichment_all_results.csv` contains all GO terms returned by the enrichment test and their raw and FDR-adjusted p-values.  
`GO_enrichment_raw_p05.csv` contains GO terms with `raw p-value < 0.05`
`GO_enrichment_FDR05.csv` contains GO terms with `FDR < 0.05`
`GO_enrichment.png`  
`GO_enrichment.pdf`  
`GO_enrichment.svg`
saved in: `r_results/`.
The enrichment plot displays GO terms with raw p-value < 0.05 and distinguishes terms that also remain significant after FDR correction.
SVG format is useful for opening figures in vector graphic editors such as Inkscape, allowing manual adjustment and editing of individual image elements without loss of quality.

### Usage
- Run `prepare_GO.sh` before running the R workflow.
- Ensure the required R packages are installed.
- The current analysis uses the Gene Ontology `Biological Process` (`BP`) ontology.
- The minimum GO-term size is currently set to 3 genes.
- The enrichment test uses the `weight01` algorithm with Fisher's exact test.
- FDR correction is performed across all GO terms returned by the enrichment analysis before filtering for significance.
- Update the following in `GO_enrichment.R` if needed:
```
data_dir <- "bash_results"
output_dir <- "r_results"
```
- Adjust the ontology and minimum GO-term size as needed:
```
ontology = "BP"
nodeSize = 3
```
