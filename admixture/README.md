# ADMIXTURE Analysis Pipeline

## Overview
This workflow performs ADMIXTURE analysis ancestry estimation from filtered SNP datasets using ADMIXTURE and visualizes ancestry proportions using R.

The pipeline includes:

- Conversion of filtered SNP datasets into PLINK format
- ADMIXTURE analysis across multiple K values
- Cross-validation (CV) error evaluation
- Selection of optimal K value
- Preparation of ancestry proportion tables
- ADMIXTURE barplot visualization

See:
`admixture.sh`
`admixture.R`

## 1. Bash ADMIXTURE Workflow

### Purpose
The bash workflow performs ADMIXTURE analyses across multiple K values using filtered SNP datasets.

The script performs:

- Convert VCF to PLINK BED format
- Run ADMIXTURE for multiple K values
- Perform cross-validation (CV) analysis
- Generate log files for each K value

### Expected Input
Filtered SNP dataset after LD pruning
`snps_afterLD.vcf`

### Output
`adinput.bed`
`adinput.bim`
`adinput.fam`

`log1.out`
`log2.out`
`...`
`log10.out`

`adinput.1.Q`
`adinput.2.Q`
`...`
`adinput.10.Q`

`adinput.1.P`
`adinput.2.P`
`...`
`adinput.10.P`

`adinput.1.Q_bias`
`adinput.2.Q_bias`
`...`
`adinput.10.Q_bias`

`adinput.1.Q_se`
`adinput.2.Q_Se`
`...`
`adinput.10.Q_se`

### Important Notes
- `kvalue.csv` was created manually using the cross-validation (CV) error values extracted from the ADMIXTURE log files (log*.out).
- The optimal K value was selected based on the first lowest CV error.
- After selecting the preferred K value, the corresponding .Q ancestry proportion file was manually converted into CSV format and sampling site metadata (e.g., Region, Location, SampleID) were added manually before visualization in R.

### Usage
- This script was run using `ADMIXTURE v1.3.0`. Ensure `ADMIXTURE` is installed and available in your environment.
- Adjust SLURM job settings (partition, CPUs, memory, runtime, output paths, etc.) based on your cluster configuration and dataset size.
- Adjust the range of K values and parallelization settings as needed for your dataset and computational resources.
- Update the following in `admixture.sh`:
```
/admixture_results/logs/admixture.out
/admixture_results/logs/admixture.err
/path/to/output_directory
/path/to/plink
/path/to/snps_afterLD.vcf
/path/to/admixture
```
- Submit the job:
`sbatch admixture.sh`

## 2. R ADMIXTURE Visualization Workflow

### Purpose
The R workflow visualizes ADMIXTURE ancestry proportions and cross-validation error results.

The script performs:

- Import CV error values
- Generate CV error plots
- Load ancestry proportion data
- Reshape ancestry proportion tables for plotting
- Generate ADMIXTURE barplots
- Export figures in PDF, PNG, and SVG formats

### R Packages
The script requires:

- `ggplot2`
- `dplyr`

### Expected Input
can be found in `r_data/` folder:
- Cross-validation error table
`kvalue.csv`
- Selected ancestry proportion table (in this study, k = 5)
`adinput.5.Q.csv`

### Output
`cv_error.png`
`admix_k5.csv`
`admix_k5.pdf`
`admix_k5.png`
`admix_k5.svg`
saved in: `r_results/`. SVG format is useful for opening figures in vector graphic editors such as Inkscape, allowing manual adjustment and editing of individual image elements without loss of quality.

### Usage
- Adjust the selected K value, plotting order, color palettes, and figure dimensions as needed for your dataset and visualization goals.
- Update the following in `admixture.R` if needed:
`data_dir <- "r_data"`
`output_dir <- "r_results"`
`k_value <- 5`
