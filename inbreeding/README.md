# Inbreeding Analysis Pipeline

## Overview
This workflow estimates and analyzes genomic inbreeding using two complementary approaches: the inbreeding coefficient based on observed and expected homozygosity (FIS) and the proportion of the callable genome contained within runs of homozygosity (FROH).

The pipeline includes:

- Estimation of individual inbreeding coefficients using VCFtools
- Detection of runs of homozygosity (ROH) using PLINK
- Calculation and summary of FIS and FROH
- Statistical comparison of inbreeding coefficients among genetic clusters
- Summary of ROH characteristics and length distributions
- Comparison of FIS and FROH
- Visualization of inbreeding and ROH patterns

See:
`inbreeding_fis.sh`
`inbreeding_roh.sh`
`inbreeding_analysis.R`

## 1. FIS Estimation

### Purpose
The `inbreeding_fis.sh` workflow estimates individual-level observed and expected homozygosity and the inbreeding coefficient (F) using VCFtools.

The script performs:

- Read an LD-pruned autosomal biallelic SNP dataset
- Select individuals from each genetic cluster
- Calculate individual inbreeding statistics using `vcftools --het`

### Expected Input
- LD-pruned SNP dataset:
`snps_afterLD_unrelated.vcf`
- Sample list for each genetic cluster:
`<cluster_name>.samples.txt`

Each sample list should contain one sample ID per line, matching the sample IDs in the VCF. For example:

```
sample001
sample002
sample003
sample004
sample005
```

### Output
VCFtools heterozygosity/inbreeding output for each genetic cluster:
`<cluster_name>.het`

### Usage
- This script was run using `vcftools v0.1.17`. Ensure `vcftools` is installed and available in your environment.
- Update the input VCF, sample list, and output paths in `inbreeding_fis.sh`.
- Run the command separately for each genetic cluster as needed.


## 2. ROH Estimation

### Purpose
The `inbreeding_roh.sh` workflow identifies runs of homozygosity (ROH) using PLINK.

The script performs:

- Read a SNP VCF restricted to callable genomic regions, generated by `4_callable_vcf.sh` from the `callable_genome` workflow.
- Identify ROH using specified PLINK homozygosity parameters
- Generate individual- and segment-level ROH results

### Expected Input
SNP dataset restricted to callable genomic regions:
`snps_callable.vcf.gz`

### Output
PLINK ROH output files, including:
`roh.hom`
`roh.hom.indiv`
`roh.hom.summary`
`roh.nosex`
For downstream analysis in `inbreeding_analysis.R`:
- `roh.hom` contains **individual ROH segments** and is used to summarize ROH length, number, and distribution.
- `roh.hom.indiv` contains **individual-level ROH summaries** and is used to calculate \(F_{ROH}\).

### Usage
- This script was run using `plink v1.9`. Ensure `plink` is installed and available in your environment.
- Adjust the SLURM job settings (partition, CPUs, memory, runtime, log paths, etc.) based on your cluster configuration and dataset size.
- Update the following in `inbreeding_roh.sh`:
```
PLINK="/path/to/plink"
VCF="/path/to/snps_callable.vcf.gz"
OUT="/path/to/output/roh"
```
- Submit the job:
`sbatch inbreeding_roh.sh`


## 3. R Inbreeding Analysis

### Purpose
The `inbreeding_analysis.R` workflow summarizes and visualizes FIS and ROH-based inbreeding results and compares inbreeding patterns among genetic clusters.

The script performs:

- Import and combine VCFtools `.het` files
- Calculate summary statistics for FIS
- Calculate FROH using total ROH length and callable genome size
- Perform Kruskal-Wallis and pairwise Wilcoxon tests
- Generate significance letters for pairwise comparisons
- Summarize ROH number and length
- Calculate the proportion of ROH segments across length categories
- Summarize ROH distribution across chromosomes
- Test the correlation between FIS and FROH
- Generate and export figures and summary tables

### R Packages
The script requires:
- `dplyr`
- `ggplot2`
- `patchwork`
- `multcompView`

### Expected Input
The following files should be placed in `r_data/`:
- VCFtools heterozygosity/inbreeding files (`<cluster_name>.het`). In our study:
```
merritt.het
sl.het
cbc.het
sbc.het
archbold.het
ocala.het
```
- ROH data prepared from PLINK output:
`roh.hom.indiv.csv`  
`roh.hom.csv`  
`roh.hom_chr.csv`

The PLINK output files were manually converted to CSV format, and genetic cluster information was added for downstream analysis.
- `roh.hom.indiv.csv` was prepared from `roh.hom.indiv` and contains individual-level ROH summary information.
- `roh.hom.csv` was prepared from `roh.hom` and contains individual ROH segment information.
- `roh.hom_chr.csv` was derived from `roh.hom.csv` by retaining only ROH segments from the chromosomes included in the chromosome-level analysis. An additional column containing the chromosome number (`CHR_NUM`) was added for plotting and summarizing the distribution of ROH segments across chromosomes.

### Output
Results, all figures and tables, are saved in `r_results/` and include:
- FIS summary and statistical tests
- FROH summary and statistical tests
- ROH summary statistics
- ROH length distribution results
- ROH chromosome distribution results
- FIS–FROH correlation results
- Inbreeding and ROH figures in PDF, PNG, and/or SVG formats

### Important Notes
- The callable genome size used to calculate FROH is defined by:
`callable_genome_mb <- 948.29`

This value was obtained from the output of `3_common_callable.sh` in the `callable_genome` workflow. The script calculates the total size of the final merged common callable regions and reports it in the `common_callable.out` log file. This value is used as the denominator for calculating FROH and should be updated based on the callable genome size obtained for each dataset.

- The genetic cluster names and plotting order are defined in:
```
clusters <- c(
"Merritt Island",
"SL",
"CBC",
"SBC",
"Archbold",
"Ocala"
)
```

### Usage
- Place the required input files in `r_data/`.
- Update the callable genome size, cluster names, file names, and colors as needed.
- Update the following in `inbreedding_analysis.R` if needed:
`data_dir <- "r_data"`
`output_dir <- "r_results"`
